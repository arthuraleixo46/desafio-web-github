# Desafio Git & Github - Explorando Colaboração e Markdown

O Markdown é uma linguagem de marcação simples usada para formatação de texto. Aqui estão alguns exemplos básicos de como utilizar o Markdown.

---

## 1. Títulos

O Markdown permite a criação de títulos usando o símbolo `#`. Quanto mais `#`, menor o nível do título.

### Exemplo de Títulos:

```
# Título 1
## Título 2
### Título 3
#### Título 4
##### Título 5
###### Título 6
```

## 2. Negrito e Itálico

Você pode usar `*` ou `_` para criar texto em itálico e `**` ou `__` para negrito.

### Exemplo de Negrito e Itálico:
```
**Texto em negrito**
*Texto em itálico*

__Texto em negrito com underscores__
_Texto em itálico com underscores_
```

## 3. Listas

O Markdown suporta tanto listas ordenadas quanto não ordenadas.

### Exemplo de Lista Não Ordenada:
```
- Item 1
- Item 2
- Item 3
```

### Exemplo de Lista Ordenada:
```
1. Primeiro item
2. Segundo item
3. Terceiro item
```

## 4. Links

Você pode inserir links com a sintaxe apropriada.

### Exemplo de Link:
```
[GitHub](https://github.com)
```
